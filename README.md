BOLT11-shaped invoice helper — stub fields.

## Features

- BTC path m/84'/0'/0'
- Deterministic digest (stdlib, no crates)
- Vault + account derive
- cargo test covers keys and wallet

## Prerequisites

- Rust 1.75+
- Git

## Getting Started

```bash
git clone <repo-url>
cd lightning-bolt11
cargo build --release
./target/release/lightning-bolt11 --help
```

## Tests
